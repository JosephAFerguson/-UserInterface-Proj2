Pre-design
Characterizing the Affordances and Physical Properties of the Object

Our object is a bookshelf.
It is not portable nor small. The bookshelf is meant to be in a household room, placed on the floor.
Usually, it has shelves with books on them. Sometimes, bookshelves are smaller bedside additions.

Capturing User Needs
Interview 1: Anonymous

Q1: What features would you want a smart bookshelf to have?
A1: I'd like the smart bookshelf to automatically add my books when I place them on the shelf, maybe using ISBN barcode scanning. I would like to be able to view my catalog of books on an app when I’m away from the library.

Q2: What would you like to see for your collection of books?
A2: I would like to see the books I have or have not read, my progress or notes for the books. I would like my collection to be sorted the way I like. I would like to see the books I have lent to other people or the books I have forgotten to place back on the bookshelf.

Q3: How simple would you like the smart bookshelf to be?
A3: I would like my bookshelf to be very simple, where I can just add or remove books without interruption.

Interview 2: Anonymous

Q1: What features would you want a smart bookshelf to have?
A1: A way to track my reading, and features that support organization. I guess reminders will also be good to help with consistency for my reading goals. It would also be a plus if my bookshelf is beautiful.

Q2: What would you like to see for your collection of books?
A2: Genres and authors. Reading speed; tracking the time it takes me to finish a book might be fun.

Q3: How simple would you like the smart bookshelf to be?
A3: Easy to use; not a steep learning curve. Powerful but seamless.

Interview 3: Anonymous

Q1: What features would you want a smart bookshelf to have?
A1: I would like to be able to see how often I’m grabbing certain books and how many books I have on it at any time.

Q2: What would you like to see for your collection of books?
A2: I would like to be able to see the genre, synopsis, author, and other important details about each book.

Q3: How simple would you like the smart bookshelf to be?
A3: I would like the bookshelf to be as simple as possible and look just like a normal bookshelf. I would also like the UI to be simple and quick to use as well.

State Your Assumptions

Bookshelf can detect and scan new books being added (via cameras/scanners) and detect a book being removed.

Bookshelf can store history of books over time.

Bookshelf has smart LED lights to highlight books for the user.

Written List of User Needs and Design Requirements

Need to see books

Need to be able to see book details (title, summary, author, etc.)

Need ability to add and remove books

Need ability to sort/find books using LED lights

Need ability to track usage of books (on/off shelf)

Need ability to store history of bookshelf

Documentation
Describe the Project

Our project is a Smart Bookshelf.
This smart bookshelf tracks metrics about your usage for each book, the dates of the books, and characteristics of each book.
It also has a search and sort feature that utilizes LED lights on the bookshelf to help you find books.

Present Your Design Work

Listed in the first half of the document.
We started with idea gathering, which led to the idea of the smart bookshelf.
Then, we each did 10×10 sketches, discussed what we liked and disliked, and produced refined layouts.
After formulating our layout and features, we began template development, followed by iterative design and implementation.

Implementation Details

No libraries were used.

Code was split into separate Svelte files for modular collaboration.

Git & GitHub were used for version control and project management.

Optional – Use of AI

We used AI as a problem-solving aid for specific cases:

Fixing text overflow in the BookSvg.svelte file (responsive text sizing).

Data generation for the 70+ books and profiles.

All boilerplate and design work were done manually without AI assistance.

Future Work

Future improvements could include:

Increasing bookshelf capacity (currently 40 books).

Creating a family bookshelf mode, allowing shared LED indication and tracking.

Developing a mobile app for remote access and reading statistics.

Adding more tracking metrics (reading sessions, prices, virtual books, etc.).

Implementing LED lights that update dynamically during search operations.
