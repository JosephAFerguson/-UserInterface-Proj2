•	Describe the project
Our project is a smart bookshelf. This smart bookshelf tracks metrics about your usage for each book, the dates of the books, and characteristics of each book. It also has a search and sort feature that utilizes led lights on the bookshelf to help you find books on your bookshelf.
•	Present your design work-
Listed in the first half of the document. Essentially we started with idea gathering, which then led us to the idea of the smart bookshelf. Then, we each did 10x10 sketches with the idea in mind. After that we talked about what we liked and disliked from each sketch, and then we did more. After that we formulated a list and loose layout of what we wanted, and we started the template development. During this process, we narrowed down the design until we had a solid boilerplate and vanilla sketch. After this the rest was development and implementation.

•	Explain how you implemented this application (libraries, code structure....)
We did not use any libraries for this project. Because it was a team project, we split our code into separate svelte files for each part of the project so that everyone could work on a part of the project without conflicting with another individual’s changes. We used git & GitHub for project management that really helped our workflow. 
•	Optional- Use of AI-  If you used AI, describe how.  Did you identify strengths/limitations of using AI for your application.  
We used AI as an aid for specific problems we ran into. For instance, we had a problem with the BookSvg svelte file having text overflow the size of the book, but only on different profiles than the default one. To solve this problem, we utilized the built-in copilot to change the text size to update when the user selects a different profile. 
We also used AI for data generation, specifically the 70+ books and details we store for the different profiles. This would have taken a lot of time to type out manually, so AI was used for this.
For everything else, including boiler plating and design work, everything was done without AI.
•	Future work- No project is ever fully done. What would you do next?  This is also a place to discuss the work you attempted but could not fully complete before the project deadline- include screenshots to illustrate and document your progress. 
We believe the scale of the project can be improved in the future. For instance, our capacity of 40 books may not be enough for dedicated readers. Also, we can further develop the smart bookshelf to make it into a family smart bookshelf. This would be a single shared bookshelf where everyone can see their books using the LEDs, instead of separate bookshelves for each individual (which is what we are displaying now).
We can also integrate a secondary, mobile app so that users can see their bookshelf from anywhere. It could also include more tracking information such as reading sessions & pages read, prices of books online, purely virtual books in their bookshelf, and more. Searching will update the led lights to show which books match the search terms.
